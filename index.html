Firebase सेटअप बाकी है

पहली बार सेटअप

यह वेबसाइट Firebase के Free (Spark) प्लान पर चलने के लिए बनाई गई है। ऑनलाइन डेटा चालू करने के लिए नीचे Firebase की Web App Config भरनी होगी। यह जानकारी Firebase Console में मिलेगी।

Config आपके इसी ब्राउज़र में सेव होगा। Firebase की सुरक्षा Firestore Rules और Login से होगी।
